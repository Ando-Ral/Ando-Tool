ANDO TOOL CARNET V3
Auteur : Ralambomanana Ando

1. Choisir un JSON.
2. Choisir Mode Simple ou Mode Rapide.
3. Laisser l'application ouverte/en arrière-plan.
4. Utiliser les raccourcis dans l'application de saisie cible.

Navigation :
Ctrl+Alt+O = précédent
Ctrl+Alt+P = suivant

Compilation depuis Android :
Le fichier .github/workflows/build-windows.yml demande à GitHub Actions
d'utiliser un runner Windows, d'installer Python et les dépendances, puis
de créer dist/AndoToolCarnet.exe avec PyInstaller.

Dans GitHub :
Actions > Build Ando Tool Carnet for Windows > Run workflow.
Puis ouvrir le job terminé et télécharger l'artifact AndoToolCarnet-Windows.
